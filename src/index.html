Reference sheet

Builds a prompt for one image showing the same subject from several angles, with flat lighting and a plain background. That's the input image-to-3D tools (Tripo, Meshy and similar) work best with, and it keeps a design consistent across later images.

You can still edit it after.

Make 3D model

Sends the image to Tripo, which builds a textured 3D model (.glb) you can rig in Mixamo or import into Godot, Unity or Blender. It usually takes a minute or two.

Tripo needs the front view and at least one more. Three-quarter and top views don't fit its slots, so leave them out. If the model comes out mirrored, swap Left and Right.
